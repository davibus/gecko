# Scratch research ideas

These are proposals, not approved new columns.


 |  | Column Ideas

 |  | Proposed column | Information to capture
 |  | Main Responsibilities | A short summary of what you would actually do
 |  | Preferred Qualifications | Helpful qualifications that are optional
 |  | Schedule | Working hours, shifts, weekends, overtime, on-call duties
 |  | Management Scope | Individual contributor or manager; team size if stated
 |  | Reporting To | Department and supervisor’s title
 |  | Application Deadline | Stated closing date
 |  | Application Requirements | Cover letter, portfolio, screening questions, assessments
 |  | Employer Job ID | Requisition number for identifying duplicates and following up
 |  | Direct Employer Posting | The employer’s original listing when your link is an aggregator
 |  | Hiring Contact | A publicly listed recruiter or hiring contact
 |  | Sponsorship / Work Authorization | Explicitly stated eligibility and sponsorship policy
 |  | Relocation Assistance | Whether relocation support is offered
 |  | Contract Details | Duration, renewal possibility, employee versus contractor
 |  | Information Source | Supporting URL and date checked

 |  | Looking beyond the individual job posting, Firecrawl could also research company websites for:

 |  | Proposed column | Information to capture
 |  | Industry / Products | What the company does and sells
 |  | Company Size | Published employee count or approximate range
 |  | Company Ownership | Public, private, subsidiary, or nonprofit
 |  | Recent Company Developments | Dated announcements about expansion, funding, acquisitions, or layoffs
 |  | Other Relevant Openings | Additional roles at the same company

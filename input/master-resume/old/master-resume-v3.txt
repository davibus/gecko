What I built and what it does
•	Custom storefront: Presents UTV parts through branded home-page sections, product collections, responsive navigation, product galleries, variant selection, pricing, and related-product recommendations.
•	Product discovery: Provides predictive search, full search results, sorting, pagination, and filters for attributes such as availability, vendor, product type, price, and product options.
•	Shopping cart: Supports adding products, changing quantities, removing items, calculating totals, retaining a cart through cookies, and handing customers to Shopify checkout.
•	Responsive interactions: Uses shared optimistic cart state to show changes immediately while server actions confirm the update with Shopify.
•	Customer accounts: Supports registration, sign-in, sign-out, password recovery, profile updates, address management, and order-history views.
•	Commerce integration: Retrieves and normalizes Shopify products, collections, menus, pages, policies, customer records, and cart data through typed GraphQL operations.
•	Product advertising feed: Generates a variant-level Google Merchant Center XML feed with prices, availability, images, identifiers, categories, product options, vehicle-make details, and custom labels.
•	Product data consistency: Uses a shared offer model for the merchant feed and product-page structured data so price, availability, identifiers, and variant information are derived consistently.
•	Marketing analytics: Implements GA4 events for product-list impressions, product selection and views, cart interactions, searches, filters, contact clicks, calls to action, and successful login or registration.
•	Technical SEO: Provides canonical URLs, index controls, pagination validation, permanent redirects, XML sitemaps, robots rules, product structured data, and social-sharing metadata.
•	Content and policies: Displays Shopify-managed content and business policies, with a script for publishing policy documents to Shopify so storefront and checkout content can stay aligned.
•	Cache refresh and monitoring: Uses Shopify webhook topics to invalidate relevant cached data, provides feed statistics, and includes a scheduled GitHub Actions workflow to warm the feed cache and check for an unexpectedly low item count.
How the workflow operates
11.	A visitor opens the custom Next.js storefront and browses products, collections, or search results.
12.	Server-side functions request Shopify data through GraphQL, normalize the response, and cache reusable catalog information.
13.	Product pages display the available variants and update the selected product state as the customer chooses options.
14.	Cart actions update the interface immediately, submit the change to Shopify, and reconcile the displayed cart with the confirmed response.
15.	The customer continues to Shopify-hosted checkout to complete the purchase.
16.	GA4 records storefront interactions; the documented measurement setup assigns checkout and purchase events to Shopify to prevent duplicate reporting.
17.	Shopify product and collection webhooks refresh the affected caches. The feed, structured data, and storefront use the same underlying catalog information.
18.	The deployment configuration packages the application in Docker for Railway, with a health check and restart policy; project documentation identifies Cloudflare in front of the storefront.
